# Source2Boost

Оптимизатор Counter-Strike 2 для максимума FPS и ровного фреймтайма — **на любом железе**, от старого i7-6700 до топового Ryzen 7800X3D. Понятен новичку, красивый минималистичный интерфейс (Fluent), русский / українська / English.

> **Не только для слабых ПК.** Source 2 упирается в один поток и в топологию CPU, поэтому даже мощная система может дёргаться или недодавать FPS (условно 300 вместо 500). Source2Boost лечит именно это: подбирает профиль под конкретное железо, сажает CS2 на быстрые ядра/кэш-CCD и сглаживает фреймтайм — а не просто «отключает службы, как все».

## Чем отличается от `cs2-omz` и `CS2 Ultimate Optimization`

Это не «то же самое в обёртке». Консольные скрипты применяют фиксированный список твиков и уходят. Source2Boost — приложение, которое **измеряет, адаптируется и умеет всё откатить**:

| Возможность | cs2-omz / Ultimate Optimization | **Source2Boost** |
|---|:---:|:---:|
| Живой бенчмарк фреймтайма (PresentMon), режим «до/после» | ❌ | ✅ |
| Профиль подбирается под конкретное железо (классификатор) | ❌ | ✅ |
| Аффинити CS2 по топологии CPU (P-ядра / кэш-CCD), авто-переприменение | ❌ | ✅ |
| Автоочистка standby-памяти каждые 5 мин (анти-стуттер, ISLC-подобно) | ❌ | ✅ |
| Авто-режим «игровой фокус» (буст при запуске CS2) | ❌ | ✅ |
| Бэкап реестра + точка восстановления + откат каждого твика в 1 клик | ❌ | ✅ |
| Советник по BIOS под ваше железо | ❌ | ✅ |
| Лаборатория: экспериментальные твики с проверкой замером | ❌ | ✅ |
| Графический интерфейс, RU / UK / EN, авто-обновление | ❌ | ✅ |

## Что умеет

- 🔎 **Сканирует железо** и ставит диагноз (CPU-bound? память? топология CPU? частота монитора?), затем **сам рекомендует профиль** под вашу конфигурацию.
- ⚡ **Два режима**: «Оптимизировать» в один клик и продвинутый чек-лист с галочками по каждому твику (риск + эффект).
- 🧠 **Лечение движка Source 2**: аффинити CS2 на быстрые ядра (P-ядра у Intel-гибридов, кэш-CCD у многочиплетных Ryzen) — то, что вытягивает FPS/плавность на мощном железе.
- 🖥 **Системные твики**: timer resolution, MMCSS, питание/core parking, MPO, службы, реестр (40+ твиков, каждый с уровнем риска и откатом).
- 🎮 **Настройки CS2**: генерация `autoexec.cfg` и launch options под твоё железо и герцовку, отключение Reflex/FidelityFX, ремонт битого кэша шейдеров.
- 🌐 **Сеть**: Nagle off, QoS-приоритет пакетов CS2, сетевой троттлинг.
- 📈 **Мониторинг**: живой график FPS/фреймтайма (PresentMon), режим «до/после» для проверки любого изменения.
- 🧪 **Лаборатория**: экспериментальные твики вне профилей — включаешь, меряешь бенчмарком, оставляешь только то, что реально помогло.
- ↩️ **Безопасность**: бэкап реестра + точка восстановления Windows перед каждым применением, откат в один клик.

## Стек

C# / .NET 8 · WPF + WPF-UI (Fluent) · PresentMon · установщик Inno Setup (`setup.exe`).

## Структура

```
src/Source2Boost.App    WPF-интерфейс (Fluent), ViewModels, локализация
src/Source2Boost.Core   движок твиков, детект железа, CS2-конфиги, бэкап/откат
tools/                  PresentMon (мониторинг фреймтайма)
installer/              скрипт Inno Setup
docs/                   TWEAKS.md — каталог твиков + прочая документация
```

## Требования

Windows 10/11 x64. Программа запрашивает права администратора (нужны для системных твиков). VAC-safe: не вмешивается в процесс игры.

## Сборка

```powershell
dotnet build Source2Boost.sln -c Release
# сборка установщика:
dotnet publish src/Source2Boost.App/Source2Boost.App.csproj -c Release -r win-x64 --self-contained true -o publish
& "C:\Program Files (x86)\Inno Setup 6\ISCC.exe" installer\Source2Boost.iss
```
