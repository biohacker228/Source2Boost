# assets

## `s2b_bench.dem` — эталонная демка для авто-замера

Положи сюда файл **`s2b_bench.dem`** — эталонную запись игры для кнопки «Авто-замер по демке».

Как записать (один раз):
1. В CS2: **Настройки → Игра → Включить консоль разработчика**.
2. Зайди в дефматч на **de_dust2**.
3. Консоль (`~`): `record s2b_bench`
4. Играй ~60 сек активно (движение, стрельба, смоки, «тяжёлые» участки).
5. Консоль: `stop`
6. Файл `s2b_bench.dem` появится в `...\Counter-Strike Global Offensive\game\csgo\replays\`.
   Скопируй его сюда, в `assets\`.

Что дальше (автоматически):
- Установщик (`installer\Source2Boost.iss`) кладёт демку рядом с приложением, если она есть здесь.
- Приложение (`Cs2Benchmark.EnsureReferenceDemoInstalled`) само копирует её в `...\csgo\replays\`
  при первом авто-замере — **конечный пользователь консоль не открывает**.

Примечание: после крупных обновлений CS2 демка может перестать воспроизводиться (движок
меняет формат) — тогда перезаписать и заменить файл здесь, разослать через авто-апдейт.
