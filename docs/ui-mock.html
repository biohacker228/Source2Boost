Оптимизация в один клик

Выбери профиль — применим весь набор твиков сразу. Всё с бэкапом и откатом.

Безопасныйриск 0
Только полностью обратимые твики. Скромный, но гарантированный прирост. Для друзей по умолчанию.
Максимумагрессивно
Глубокие твики CPU, памяти, служб и драйвера. Больше FPS, точка восстановления перед стартом.
Бенчмарквременно
Предельный профиль для замера. Авто-откат после теста «до/после».

Настройки CS2

Сгенерировано под твоё железо и 180 Гц. Без мусорных CSGO-флагов.

C:\…\Counter-Strike Global Offensive
Параметры запуска 
-novid -console -nojoy -high -fullscreen -freq 180 +fps_max 0 -softparticlesdefaultoff +exec autoexec
autoexec.cfg 
// FPS / фреймтайм
fps_max 0
engine_no_focus_sleep 0
// сеть (sub-tick)
rate 786432
cl_forcepreload 1
// разгрузка рендера
cl_disable_ragdolls 1
muzzleflash_light 0
Запишем autoexec.cfg в папку cfg и подставим параметры запуска в Steam.
